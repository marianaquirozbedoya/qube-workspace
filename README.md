# Qube Workspace

## Project Description
This project consists of the development of a dashboard user interface for workspace management. It is an initial learning and frontend development project designed to consolidate modern development workflows. The visual interface implements a glassmorphic design style based on layered translucency, utilizing an optimized dark-mode color palette focused on steel blue and deep slate tones.

## Purpose and Objective
The primary objective of this repository is to build a controlled testing environment to experiment with interactive user interface layouts, component separation, and global style configurations. It was created as a first development milestone to establish a solid web development foundation before connecting external database services or APIs.

## Technical Specifications and Tooling
The project infrastructure is composed of the following technologies:
* **React 19:** The primary library utilized to build the interface through functional JavaScript components.
* **Vite:** The build tool and development server handling fast compilation and Hot Module Replacement (HMR).
* **Tailwind CSS v4:** The styling framework used to structure the visual layout directly through utility classes within the code.
* **PostCSS and Autoprefixer:** Supporting tools responsible for compiling styles and ensuring cross-browser compatibility for modern web browsers.
* **Git:** The version control system used to track code changes through structured commit messages.

## Installation and Local Deployment Guide

### Prerequisites
Node.js must be installed on your system to execute the package management commands.

### Configuration Instructions and Server Execution
```bash
# 1. Clone the repository locally from GitHub
git clone [https://github.com/marianaquirozbedoya/qube-workspace.git](https://github.com/marianaquirozbedoya/qube-workspace.git)

# 2. Navigate into the project directory
cd qube-workspace

# 3. Install the system dependencies and packages
npm install

# 4. Start the local development environment
npm run dev
